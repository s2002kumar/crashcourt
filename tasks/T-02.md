## Decisions
1. **LG-DE-RERUN's source moved.** The guidance used to be on the Durable Execution page. Upstream removed that page on
   2026-05-27 (langchain-ai/docs#3979, commit 2a8ace1db7, "remove LangGraph Durable Execution docs page"), and its URL
   now redirects (308) to Persistence. The same guidance now lives in the Graph API page's "Re-execution and
   idempotency" section, which the clause cites, and in the Functional API page's "Idempotency" section, which the
   clause notes quote ("may run again"). Polarity and meaning are unchanged, and the paraphrase follows the new
   wording. I chose the Graph API page because the workloads here are graphs of nodes, not functional-API tasks.
2. **`quotes` field.** The card asks for the interrupts clause "captured exactly". Every clause now carries one or more
   verbatim sentences as rendered (markup dropped). `--refetch` checks each quote against the live page. The page hash
   drifts on any edit anywhere on a page, but a missing quote means the cited wording itself changed. The quotes are a
   few sentences each, not copies of pages.
3. **`snapshot_url` field.** Docs pages are hashed through their Markdown source (`<page>.md`), which returned
   byte-identical content on repeated fetches; the rendered HTML carries build-specific markup. LG-OWN-8796 hashes
   the proposal's README in bharatnpti/langgraph-write-ownership on `main` (identical to commit 9cfadc5), so a refetch
   shows when the proposal changes; the GitHub issue page itself changes with every comment.
4. **Version scopes are the pinned minor lines** (`langgraph >=1.2,<1.3`, `langgraph-checkpoint >=4.2,<4.3`), not the
   version a feature first appeared in. I read the docs against the pinned release, so a version bump has to re-read
   the clauses before verdicts may cite them again. LG-OWN-8796 is scoped to the conformance release its patch
   targets (0.0.2) and notes that it is in no release.
5. **Paraphrases stay at or below the docs' strength; my own readings are in `notes`, marked as mine.** My open
   questions: whether LG-DUR-SYNC's "written" means "the saver's put returned"; whether LG-PW, which the docs frame
   around a node failing, also covers a process crash (and it does not hold mid-run under exit durability); that
   double and conflicting resumes have no clause (GAP); and whether a describes clause such as LG-LATEST can support a
   verdict on its own.
6. **Refetch never fails the build.** Validation errors exit 1; drift, missing quotes, fragments the page does not
   define, and unreachable or undecodable sources are reported with exit 0, as the card says. Drift is a prompt to
   re-read a source.
7. **A new reference manifest for C7.** The new dependencies changed uv.lock, and CI's doctor job failed on the
   lockfile hash against the T-01 manifest, which is what C7 should do
   ([run 36316877631](https://github.com/s2002kumar/crashcourt/actions/runs/36316877631)). The reference for this
   branch is research/evidence/t-02/manifest-local.json, and CI points at it. Any later task that changes a pinned
   field does the same; the reference test checks the one CI compares against, since older references keep the
   schema of their time.
8. **The manifest records the registry's version.** `clause_registry_sha256` is a sha256 over every clause file's path
   and LF-normalized bytes, so it is the same on every platform and changes with any edit, addition, removal, or
   rename. doctor validates the registry before recording it, and a comparison fails when two runs used different
   clauses, because verdicts cite these files. It is added before T-04 freezes the manifest schema, which stays at
   version 1 until then (T-01, decision 12). Main alternative: leave it to the checker card; it lost because the
   schema freezes first.
9. **Re-snapshot only when the cited wording is untouched.** On 2026-10-08 seven pages had changed. I read the
   upstream commits to the pages and to the code samples they import (research/evidence/t-02/refetch.md): front
   matter, a reflowed example, a JavaScript-only note, refreshed trace links, and a new interrupt-response-schema
   section; none touches a quoted sentence or a cited section. Those clauses now
   carry the new hashes and `retrieved: 2026-10-08`. Had a change touched a cited section, the clause would have been
   re-read and, if needed, rewritten.

## Candidate clauses found, not added
The card fixes the nine clauses, so these are listed on the issue rather than added:
- Interrupts, "Handling multiple interrupts": resume values are matched to interrupt calls strictly by index. Needed
  for the double and conflicting resume faults.
- Checkpointers, "Replay": interrupts are always re-triggered during replay.
- Fault tolerance, "Resume-safe failures": failure provenance is checkpointed, so an error handler sees the same
  NodeError after a crash (langgraph >= 1.2).
- Fault tolerance, "Graceful shutdown": a drained run saves a resumable checkpoint.
- Interrupts, "Define an interrupt response schema" (added upstream on 2026-09-30, langchain-ai/docs#6320): resume
  values are validated against a declared schema (langgraph >= 1.2.12).

"Handling multiple interrupts" and "Replay" come in a follow-up before the checker work, since the resume faults need
them. Graceful shutdown and resume-safe failures wait until a fault or workload uses them.

stronger than its cited source. The quotes were checked against the live pages by `clauses check --refetch` on
2026-10-08 (research/evidence/t-02/refetch.md). Two caveats stay with the clauses:
- LG-LATEST stays a describes clause. Its notes keep the mismatch between the docs, which call checkpoint ids ULIDs,
  and langgraph-checkpoint 4.2.0, which generates them with uuid6.
- LG-PW guarantees only the documented case: a node failing with an exception in a super-step. Whether it holds
  across a process crash is unresolved, and a crash does not inherit the guarantee. Its notes used to say that a
  crash-time re-run of a sibling whose writes committed could be a VIOLATION candidate with that caveat attached;
  they now say that no verdict may cite LG-PW for a crash. The paraphrase, quotes, and polarity are unchanged. The
  edit changes the registry's version, so research/evidence/t-02/manifest-local.json was re-recorded.
