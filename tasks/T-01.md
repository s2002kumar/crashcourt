## Remaining steps
1. Confirm "crashcourt" is free on PyPI (`pip index versions crashcourt`) and npm (`npm view crashcourt`).
2. `uv lock`. If resolution rejects a pin, move it to the nearest compatible release and record why here.
3. `uv sync --locked --group dev`, then `uv run ruff check . && uv run ruff format --check . && uv run pyright && uv run pytest`.
4. Confirm the newest Toxiproxy 2.x release, then `python scripts/pin_images.py`.
5. Pin every GitHub Action to a full commit SHA.
6. `docker compose up -d --wait && uv run crashcourt doctor --manifest research/evidence/t-01/manifest-local.json`; commit it.
7. Push and get both CI jobs green (the doctor job compares manifests: control C7).
8. Merge once CI is green and the G-1 gate note exists.
