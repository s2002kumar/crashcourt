## Decisions
1. **Hash chain.** Each row stores `prev_hash` and `row_hash = sha256(prev_hash | JSON of its fields)`, starting from a
   zero genesis. Verification recomputes the chain and reports the first bad `sink_seq`. A chain cannot detect the
   *last* rows being removed. The workers' `effect.response` events record each `sink_seq` they were given, which is
   the external check.
2. **One ledger file per trial.**
   - `POST /trials` opens `<data>/<batch>/<cell>/trial-NNNNN.sqlite`; the file refuses a different trial.
   - The open trial is persisted (`current.json`), so a restarted sink resumes it.
   - Per-trial files are self-contained evidence, and the ledger rows become the sink's history (`ledger_events`)
     rather than a second record written in parallel.
3. **Durability.** WAL with `synchronous=FULL`; each append and counter increment is its own committed transaction
   before the HTTP answer.
4. **A test hook in the oracle, fenced.** `CRASHCOURT_SINK_TEST_EXIT_AFTER_COMMIT` exits the process right after a
   commit. It is the only way to prove "commit before response" on a real process. It is off by default, `/health`
   reports it, and doctor fails if it is armed.
5. **Attempt counters** are keyed `model/<thread>/<node>/<turn>` and stored in the trial's ledger file. A replacement
   worker gets the next attempt.
6. **The scripted model is a plain class returning `AIMessage`, not a LangChain chat model.** It keeps the key
   explicit (thread, node, turn, attempt) instead of recovering it from callback metadata. The message id carries the
   same key, so a re-run adds a distinguishable message. T-09's workloads call it.
7. **Clock.** The ledger stamps `received_mono_ns` with the same host monotonic clock as the history writer (T-04),
   whose helper is now public.
8. **Doctor, not the manifest.** The sink is built, not pulled, so the manifest's image list (schema v1, frozen) is
   unchanged. Doctor instead checks the sink's health, its ledger version, the test hook, and that every `FROM` in
   `Dockerfile.harness` is pinned.
9. **New C7 reference.** FastAPI and uvicorn changed uv.lock. research/evidence/t-08/manifest-local.json differs from
   T-04's only in `lockfile_sha256`.
